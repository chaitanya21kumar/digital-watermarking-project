WHAT DOES EACH FILE DO?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Core Algorithm Files (in src/):

  ambtc.py
    ├─ Compresses 4×4 block into {xL, xH, bitmap}
    ├─ Generates 8-bit authentication code via hashing
    └─ Used by: watermark_embed.py

  vq.py
    ├─ Learns 256-entry codebook via KMeans clustering
    ├─ Encodes blocks to 8-bit indices
    ├─ Decodes indices back to representative blocks
    └─ Used by: watermark_embed.py, watermark_extract.py

  bd_wt_tables.py
    ├─ Generates BD table (checkerboard pattern)
    ├─ Generates WT table (wave pattern)
    ├─ Embeds 3-bit watermark per pixel pair
    ├─ Extracts 3-bit watermark from pixel pair
    └─ Used by: watermark_embed.py, watermark_extract.py

  block_mapping.py
    ├─ Creates random permutation for block selection
    ├─ Maps each block to recovery sources
    └─ Used by: watermark_embed.py, watermark_extract.py

  watermark_embed.py
    ├─ COMPLETE EMBEDDING PIPELINE:
    ├─ 1. Preprocessing (replace LSBs)
    ├─ 2. AMBTC compression
    ├─ 3. VQ codebook training
    ├─ 4. Block mapping generation
    ├─ 5. Watermark embedding
    └─ Output: Watermarked image + metadata

  watermark_extract.py
    ├─ COMPLETE AUTHENTICATION & RECOVERY PIPELINE:
    ├─ 1. Watermark extraction
    ├─ 2. AC code recomputation
    ├─ 3. Tampering detection
    ├─ 4. Tamper map refinement
    ├─ 5. Recovery via VQ lookup
    └─ Output: Tamper map + recovered image + metrics

  metrics.py
    ├─ Calculates PSNR (image quality)
    ├─ Calculates TPR, FPR, FNR (detection accuracy)
    └─ Used by: test files, experiments

  utils.py
    ├─ Image I/O (load/save PNG)
    ├─ Synthetic image generation
    ├─ Block size adjustment
    └─ Used by: ALL files

Modification Files (in src/modifications/):

  color_support.py
    ├─ Converts RGB → YCbCr
    ├─ Embeds in Y channel only
    ├─ Preserves Cb/Cr channels
    └─ Benefit: Enables color images

  sha_auth.py
    ├─ Replaces MD5 with SHA-256 hashing
    ├─ Dramatically reduces false positive rate
    └─ Benefit: Better security

  adaptive_mapping.py
    ├─ Computes entropy for each block
    ├─ Groups blocks by entropy (quartiles)
    ├─ Maps within groups
    └─ Benefit: Better quality recovery

  multilevel_recovery.py
    ├─ Tier-1: Use primary recovery source (Map1)
    ├─ Tier-2: Use backup recovery source (Map2)
    ├─ Tier-3: Interpolate from neighbors + VQ
    └─ Benefit: Works at 90%+ tampering

  post_processing.py
    ├─ Applies bilateral filtering to tampered regions
    ├─ Removes VQ blocking artifacts
    └─ Benefit: +0.8 dB prettier results
