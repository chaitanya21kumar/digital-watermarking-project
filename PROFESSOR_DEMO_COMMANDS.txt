TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════════

Q: "bash: run_comprehensive_demo.sh: command not found"
A: Make script executable first:
   chmod +x run_comprehensive_demo.sh
   Then run: bash run_comprehensive_demo.sh

Q: "ImportError: cannot import name..."
A: Make sure you're in the virtual environment:
   source venv/bin/activate

Q: "ModuleNotFoundError: No module named 'sklearn'"
A: This is okay - the system will still work, just slower
   The advanced test image generation might skip, but core watermarking works

Q: "No such file or directory: images/test"
A: The directory will be created automatically when you run the script

Q: "No results generated"
A: Check that watermarking experiments completed without errors.
   Look at the output for any error messages and fix them first.
